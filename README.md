# 🍃 Shudh - Pure Food Checker

[![React](https://img.shields.io/badge/React-19.2.3-61DAFB?logo=react)](https://reactjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.8.2-3178C6?logo=typescript)](https://www.typescriptlang.org/)
[![Vite](https://img.shields.io/badge/Vite-6.2.0-646CFF?logo=vite)](https://vitejs.dev/)

Shudh revolutionizes how you shop for groceries by instantly analyzing food ingredients for health risks, harmful additives, and nutritional quality. Point your camera at any product label and get a clear safety score in seconds.

---

## 🚀 Features

- **🔍 AI-Powered Label Scanning**: Uses computer vision to detect and read ingredients from photos automatically
- **⚠️ Ingredient Risk Analysis**: Flags harmful additives, preservatives, artificial colors, and allergens with detailed explanations
- **📊 Health Score Rating**: Gets a 1-100 safety score based on nutritional guidelines and expert standards
- **🎯 Personalized Alerts**: Customize for dietary needs like vegan, diabetic-friendly, or allergy avoidance
- **⚡ Fast & Offline Capable**: Works instantly with optional cloud sync for database lookups
- **✨ Clean, Intuitive UI**: Built with modern React/TypeScript for seamless mobile and desktop experience

## 🚀 Quick Start

### Prerequisites

- Node.js 16+ installed
- npm or yarn package manager
- Modern web browser with camera access

### Installation

1. **Clone the repository:**

```bash
git clone https://github.com/Sai-Emani25/Shudh.git
cd Shudh
```

2. **Install dependencies:**

```bash
npm install
```

3. **Run locally:**

```bash
npm run dev
```

4. **Open your browser:**

Navigate to `http://localhost:5173`

### Deployment

Deploy to Vercel or Netlify with one click:

1. Connect your GitHub repository
2. Set build command: `npm run build`
3. Set output directory: `dist`
